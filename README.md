
# CodSoft Data Analytics Internship
## Project 1: Data Cleaning and Preprocessing

### Objective
To clean a customer dataset using Python and Pandas.

### Tasks Performed
- Created a customer dataset.
- Identified missing values.
- Filled missing Age and Salary values using their averages.
- Removed duplicate records.
- Saved the cleaned dataset as a CSV file.

### Tools Used
- Python
- Pandas
- Visual Studio Code

### Output
The cleaned dataset is saved as `cleaned_data.csv`.

### How to Run
1. Install Python.
2. Install Pandas using `python -m pip install pandas`.
3. Run `data_cleaning.py`.
